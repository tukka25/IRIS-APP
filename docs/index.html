On-device model

Gemma 4 2B. Your phone, your GPU.

LiteRT-LM loads the Gemma 4 2B model and runs inference entirely on-device using the GPU backend. The planner pipeline — request analysis, capability grounding, action planning, JSON output — all executes locally. No tokens, no latency spikes, no cloud dependency.

Build it in a few steps.

Push the model to your device, run the Gradle build, open the app. Works on Windows, Linux, and macOS.

01
Clone the repo git clone https://github.com/tukka25/gemma4good_android
02
Push the model to your device adb push local_models/gemma-4-E2B-it.litertlm /sdcard/Android/data/com.irisapp/files/models/
03
Build and install .\gradlew installDebug
04
Open the app and describe a workflow. No server, no emulator, no complicated setup.
