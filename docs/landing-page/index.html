The Problem

Your apps don't talk to each other.

Modern smartphones have dozens of apps, each living in its own silo. Getting them to work together usually means learning complex automation tools or relying on cloud services you don't trust.

Siloed Apps

Calendar, SMS, maps, browser — each works in isolation. No native bridge between them.

Complex Automation

Tasker, MacroDroid, Shortcuts — powerful but require technical knowledge and manual flow design.

Cloud Dependency

Most AI automation sends your data to the cloud. Your prompts, your habits, your workflows — all remote.

Enter GemmaWorkflow

On-device AI understands what you want, builds the workflow for you, and runs it locally — no cloud, no complexity.

How It Works

Trigger System

Run workflows your way

Every workflow can run manually or be attached to a trigger. Unsupported or unfinished triggers save as "Needs Setup" — never silently fail.

Run Now

Tap "Run Now" in the workflow detail screen. Works immediately, no setup required.

Time

Schedule a workflow to run at a specific time. Persists across device reboots via AlarmManager.

NFC Tag

Write a workflow to an NFC tag. Scan the tag to run — one tap and it executes.

Share Sheet

Share content from any app to GemmaWorkflow. The AI matches the content to a workflow and runs it.

Time triggers persist across reboots — BootReceiver reschedules all triggers on startup
Get Started

Build and run in minutes

GemmaWorkflow is a native Android app. No server, no emulator, no complicated setup.

Clone the repository

Get the latest source code from GitHub.

git clone https://github.com/tukka25/gemma4good_android

Push the model to your device

One-time step: copy the Gemma 4 2B model to your Android device's app storage.

adb push local_models/gemma-4-E2B-it.litertlm /sdcard/Android/data/com.gemmaworkflow/files/models/

Build the app

Run the Gradle build. Use .\\gradlew installDebug on Windows (no Java in WSL).

.\gradlew installDebug

Describe a workflow and run it

Open the app, type a request like "Remind me to call Maya on Friday at 6pm", preview the plan, and run it.
